# Original degree-shift reference scenarios

`32C.png` and `41C.png` are the original plot images extracted without redrawing from the supplied Results/SI PDF's degree-shift section (PDF page 12). They correspond to panels A and B of Figure S1.

`reported_means.csv` transcribes the numerical bar labels from those images. `run.py --plots` redraws those reported values as `results/figures/degree_shift_reported_means.png` and `.pdf`. This reproduces the plotted values, not the original simulations.

The SI describes four modifications to the Principal Response degree-bin counts: conservative up/down shifts of the lowest occupied nonzero-degree bin, and aggressive up/down shifts of the full distribution by one bin. Networks were then built from repeatedly sampled background genes.

The original shift-analysis script, per-draw data, random seed, and exact simulation count were not present in the supplied analysis files. These panels are therefore archived artwork, not regenerated results. They are separate from the 100/500/1,000/1,500 iteration-sensitivity analysis, which is fully regenerated by `run.py`. No replacement simulations have been substituted for the original panels.
